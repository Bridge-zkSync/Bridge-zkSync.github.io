What is Bridge zkSync?

ZKsync Portal is the official app destination for deposits and withdrawals between Ethereum and ZKsync Era. ZKsync Era is a Layer 2 ZK rollup built with the ZK Stack and secured by validity proofs submitted to Ethereum; see ZKsync Era docs.

How Bridge zkSync works

  1. Connect walletOpen the portal and connect a wallet that supports Ethereum and ZKsync Era.
  2. Select routeChoose the source and destination networks, then select ETH or another supported token shown in the app.
  3. Review detailsCheck the recipient, network, amount, and wallet-estimated fees before approving.
  4. Sign and trackSubmit the transaction and use the portal or explorer to follow status.

Bridge zkSync FAQ

What is bridge zksync?

It is an app-first landing path for users who want to move assets between Ethereum and ZKsync Era, with the action sent to the official ZKsync Portal.

Is this the official ZKsync bridge app?

No. This landing page is separate from the official app; use portal.zksync.io for the transaction flow and verify the domain before signing.

Which assets can I move to ZKsync Era?

The live portal shows supported assets and routes. ETH is commonly used for funding, but token availability should always be confirmed in the app.

How long do ZKsync withdrawals take?

Timing can vary by route, wallet, and network conditions; use the app's live status and the explorer for the current transaction record.

What should I verify before using a ZKsync bridge?

Confirm the domain, wallet network, destination address, token, amount, and wallet prompt details. Treat copied links and search ads carefully.
