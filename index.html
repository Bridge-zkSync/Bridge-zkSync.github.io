What is Bridge zkSync?

ZKsync Portal is the official app destination for deposits and withdrawals between Ethereum and ZKsync Era. ZKsync Era is a Layer 2 ZK rollup built with the ZK Stack and secured by validity proofs submitted to Ethereum; Ethereum.org's zero-knowledge rollups explainer describes the validity-proof model used by ZK rollups.

ZKsync bridge fees and withdrawal time

ZKsync bridge fees include Ethereum gas for deposits, ZKsync transaction costs, token approval costs, and any finalization transaction needed for withdrawals; Etherscan's Ethereum gas tracker shows why L1 transaction costs can move with network demand. ZKsync documentation explains that withdrawals in ZKsync Chains are delayed for 3 hours as an additional security measure in its bridging assets guide. This differs from optimistic-rollup seven-day exits and from instant liquidity bridges. For direct transfers, confirm the source chain, token, received amount, and destination address before signing.

How to bridge ETH to ZKsync Era

To bridge ETH to ZKsync Era, connect an EVM wallet, select Ethereum as the source and ZKsync Era as the destination, then confirm the deposit transaction. ETH is useful because it can pay gas and interact with apps after arrival. If an ERC-20 approval is requested, the ERC-20 token standard explains the approve and transferFrom flow behind token allowances. Once the Ethereum transaction confirms and the L2 deposit is processed, check the same wallet address on the ZKsync Era block explorer. Avoid bridging only ERC-20 tokens into a fresh wallet unless you already have enough ETH or supported gas funding on ZKsync.

ZKsync supported tokens and token addresses

ZKsync supports ETH and ERC-20 bridging through default bridge contracts, but token addresses on L2 differ from Ethereum addresses. This is critical for users importing tokens manually; MetaMask's custom token display guide explains why contract addresses matter when a balance does not appear automatically. Search by the destination token contract on the ZKsync explorer and compare it with the app's accepted asset list before supplying liquidity, borrowing, or trading; chain-level context is also available on DefiLlama's ZKsync Era dashboard.

ZKsync bridge pending or not showing

A ZKsync bridge transfer may appear pending while the Ethereum transaction confirms, while the L1 to L2 message executes, or while the wallet interface indexes the updated balance. First confirm the Ethereum transaction hash, then check the ZKsync explorer for the receiving address. MetaMask's pending transaction guidance explains why low gas settings can leave Ethereum-compatible transactions waiting. If the token is an ERC-20, you may need to import the L2 token contract manually. Do not repeat the bridge transaction until the source transaction status and bridge message status are clear.

Bridge zkSync FAQ

How long do ZKsync withdrawals take?

ZKsync documentation states in its withdrawal delay documentation that withdrawals in ZKsync Chains are delayed for 3 hours for additional security. After the delay, the withdrawal can be finalized on L1. Timing can still vary with Ethereum congestion, wallet prompts, and whether a user or relayer completes the finalization step.

Why is my ZKsync token address different?

ZKsync uses different token addresses on L2 than on Ethereum L1. This is expected behavior for bridged assets. When importing a token, use the ZKsync Era contract address, not the Ethereum mainnet address; the ERC-20 interface specification is why apps identify fungible tokens by contract. DeFi apps and explorers identify assets by contract, so the wrong address can make a valid balance look missing.

Can I bridge USDC to ZKsync?

USDC availability depends on the current bridge route and whether the destination app supports native, bridged, or other representations. Check the bridge UI and the receiving protocol's token list before transferring. If there are multiple USDC-like tickers, use the contract address to choose the intended one and cross-check it with a listing source such as the CoinGecko USDC asset page.

Does ZKsync use ETH for gas?

ZKsync Era commonly uses ETH for user transaction fees, so having ETH on ZKsync is practical before using bridged ERC-20 assets. Some account abstraction or paymaster flows may sponsor or alter fee payment, but users should not rely on that unless the app explicitly supports it; L2BEAT's network profile also lists ETH as the gas token for ZKsync Era.

What is the official ZKsync bridge?

The official ZKsync bridge is available through the ZKsync portal and is intended for direct Ethereum and ZKsync asset movement. Third-party bridges can also support ZKsync, but their routes, liquidity, token outputs, and fees differ; Investopedia's cross-chain bridge explainer is a useful neutral reference for those tradeoffs. Use the official portal when canonical transfer behavior matters.

Can I bridge from Arbitrum to ZKsync?

A direct Arbitrum-to-ZKsync transfer usually requires a third-party bridge or an intermediate route because the official ZKsync bridge is centered on Ethereum and ZKsync. Compare quotes carefully and verify the output token contract on ZKsync before using the funds in DeFi; the Wired bridge security article explains why bridge design and operational controls deserve extra review.
