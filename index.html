What is Bridge zkSync?

ZKsync Portal is the official app destination for deposits and withdrawals between Ethereum and ZKsync Era. ZKsync Era is a Layer 2 ZK rollup built with the ZK Stack and secured by validity proofs submitted to Ethereum; see ZKsync Era docs.

ZKsync bridge fees and withdrawal time

ZKsync bridge fees include Ethereum gas for deposits, ZKsync transaction costs, token approval costs, and any finalization transaction needed for withdrawals. ZKsync documentation explains that withdrawals in ZKsync Chains are delayed for 3 hours as an additional security measure. This differs from optimistic-rollup seven-day exits and from instant liquidity bridges. For direct transfers, use the ZKsync Bridge and confirm the source chain, token, received amount, and destination address before signing.

How to bridge ETH to ZKsync Era

To bridge ETH to ZKsync Era, connect an EVM wallet, select Ethereum as the source and ZKsync Era as the destination, then confirm the deposit transaction. ETH is useful because it can pay gas and interact with apps after arrival. Once the Ethereum transaction confirms and the L2 deposit is processed, check the same wallet address on the ZKsync Era explorer. Avoid bridging only ERC-20 tokens into a fresh wallet unless you already have enough ETH or supported gas funding on ZKsync.

ZKsync supported tokens and token addresses

ZKsync supports ETH and ERC-20 bridging through default bridge contracts, but token addresses on L2 differ from Ethereum addresses. ZKsync docs state that L2 token addresses will always differ from the same token's L1 address. This is critical for users importing tokens manually or checking DeFi support. Search by the destination token contract on the ZKsync explorer and compare it with the app's accepted asset list before supplying liquidity, borrowing, or trading.

ZKsync bridge pending or not showing

A ZKsync bridge transfer may appear pending while the Ethereum transaction confirms, while the L1 to L2 message executes, or while the wallet interface indexes the updated balance. First confirm the Ethereum transaction hash, then check the ZKsync explorer for the receiving address. If the token is an ERC-20, you may need to import the L2 token contract manually. Do not repeat the bridge transaction until the source transaction status and bridge message status are clear.

Bridge zkSync FAQ

How long do ZKsync withdrawals take?

ZKsync documentation states that withdrawals in ZKsync Chains are delayed for 3 hours for additional security. After the delay, the withdrawal can be finalized on L1. Timing can still vary with Ethereum congestion, wallet prompts, and whether a user or relayer completes the finalization step.

Why is my ZKsync token address different?

ZKsync uses different token addresses on L2 than on Ethereum L1. This is expected and documented behavior. When importing a token, use the ZKsync Era contract address, not the Ethereum mainnet address. DeFi apps and explorers identify assets by contract, so the wrong address can make a valid balance look missing.

Can I bridge USDC to ZKsync?

USDC availability depends on the current bridge route and whether the destination app supports native, bridged, or other representations. Check the bridge UI and the receiving protocol's token list before transferring. If there are multiple USDC-like tickers, use the contract address to choose the intended one.

Does ZKsync use ETH for gas?

ZKsync Era commonly uses ETH for user transaction fees, so having ETH on ZKsync is practical before using bridged ERC-20 assets. Some account abstraction or paymaster flows may sponsor or alter fee payment, but users should not rely on that unless the app explicitly supports it.

What is the official ZKsync bridge?

The official ZKsync bridge is available through the ZKsync portal and is intended for direct Ethereum and ZKsync asset movement. Third-party bridges can also support ZKsync, but their routes, liquidity, token outputs, and fees differ. Use the official portal when canonical transfer behavior matters.

Can I bridge from Arbitrum to ZKsync?

A direct Arbitrum-to-ZKsync transfer usually requires a third-party bridge or an intermediate route because the official ZKsync bridge is centered on Ethereum and ZKsync. Compare quotes carefully and verify the output token contract on ZKsync before using the funds in DeFi.
